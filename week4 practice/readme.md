
Overview

Chapter 3 – Functions

Function Arguments

Function arguments are values passed to a function when it is called. Parameters are the variables that receive those values.

Multiple Arguments

A function can accept more than one argument to perform an operation using different values.

Returning a Value

The "return" statement is used to send a value from a function back to the place where the function was called.

Returning an Array

A function can return an array containing multiple values.

Passing by Value

Passing by value means that a copy of the original value is passed to the function. Changes inside the function do not affect the original variable.

Passing by Reference

Passing by reference allows a function to modify the original variable.

Default Argument Value

A default argument provides a value that is automatically used when no argument is supplied.

Chapter 4 – Forms

HTML Forms

Forms are used to collect information from users and send the submitted data to the server.

Form Controls

Forms can contain different controls such as textboxes, password fields, textareas, and radio buttons.

Retrieving Form Data

PHP can retrieve submitted form data using variables such as "$_GET", "$_POST", and "$_REQUEST".

Textbox

A textbox allows the user to enter a single line of text.

Password Field

A password field is used to enter sensitive text while hiding the characters from view.

Textarea

A textarea allows users to enter longer or multiple lines of text.

Radio Button Fields

Radio buttons allow users to select one option from a group of choices. Radio buttons in the same group use the same name.

Summary

Chapter 3 focuses on Functions and how values are passed and returned.

Chapter 4 introduces HTML Forms and how PHP retrieves information submitted by users.
