PHP Basics

Topics Covered

PHP
PHP is a programming language used to create websites and web applications.

Echo
Echo is used to display or output information.

Variable
A variable is used to store data. PHP variables start with "$".

Constant
A constant is a value that cannot be changed after it is created.

If Statement
An if statement is used to check a condition. If the condition is true, the code will execute.

If Else Statement
An if else statement provides two possible outcomes depending on whether the condition is true or false.

If Elseif Statement
An if elseif statement is used to check multiple conditions.

Switch
A switch statement is used to check different cases based on a value.

Summary

Topic| Purpose PHP| Programming language Echo| Display/output Variable| Stores data Constant| Stores an unchangeable value If| Checks a condition If Else| Provides two choices If Elseif| Checks multiple conditions Switch| Checks different cases
