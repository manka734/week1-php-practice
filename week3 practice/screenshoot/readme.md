PHP Arrays and Functions

This project demonstrates Multi-dimensional Arrays, Array Functions, and Functions in PHP.

1. Multi-dimensional Arrays

The code creates a student array containing:

- Name
- Year
- Location
- Phone Number

"foreach" is used to display the student information and individual array elements.

2. Array Functions

The code demonstrates common PHP array functions:

- "is_array()" – Checks if a variable is an array.
- "in_array()" – Checks if a value exists in an array.
- "explode()" – Converts a string into an array.
- "shuffle()" – Randomly changes the order of array elements.
- "array_merge()" – Combines two arrays.
- "array_reverse()" – Reverses an array.
- "array_push()" – Adds an element to the end of an array.
- "array_pop()" – Removes the last element from an array.
- "end()" – Gets the last element of an array.
- "print_r()" – Displays array contents.

3. Functions

The code also demonstrates PHP functions:

- Basic Function – A simple function that displays a message.
- Function with Parameter – A function that receives a value.
- Factorial Function – Calculates the factorial of a number using a "for" loop.
