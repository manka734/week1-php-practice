Chapter 4: PHP Forms and File Uploads

Introduction

This project demonstrates PHP forms, input validation, and file uploads.

Main Topics

* Checkbox Fields: Select multiple options.
* Drop-down Menu: Select one option.
* Listbox: Select multiple items from a list.
* File Upload: Upload one file using $_FILES.
* Multiple File Upload: Upload several files at once.
* File Validation: Check file size and extension.
* file_exists(): Checks whether a file exists.
* move_uploaded_file(): Saves uploaded files.
* Error Messages: Displays success and error messages.

File Storage

Uploaded files are saved in the Docs folder. The maximum file size is 5 MB per file, and allowed extensions are JPG, JPEG, PNG, and PDF.

Conclusion

This project teaches how to collect form data, validate inputs, upload files, and handle errors using PHP.
