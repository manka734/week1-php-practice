PHP Loops and Associative Arrays

Topics Covered

1. While Loop

Repeats code while a condition is true.

2. Do...While Loop

Executes the code at least once, then checks the condition.

3. For Loop

Repeats code a specific number of times.

4. Break

Stops a loop immediately.

5. Continue

Skips the current iteration and continues with the next one.

6. Nested Loops

A loop inside another loop.

7. Numerically Indexed Array

An array that uses numbers as indexes, starting from 0.

8. Foreach Loop

Used to go through each element of an array.

9. Associative Array

An array that uses named keys instead of numeric indexes.

10. Key => Value

The "=>" operator connects a key with its value in an associative array.
